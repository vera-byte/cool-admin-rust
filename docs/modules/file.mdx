---
title: "文件存储"
description: "local / minio / oss 三驱动与上传下载"
---

`cool-file` 提供统一的文件存储抽象，支持本地磁盘、MinIO、阿里云 OSS。

## 服务

| RPC | 说明 |
| --- | --- |
| `BaseCommService.UploadMode` | 返回上传模式（前端据此选择代理） |
| `BaseCommService.Upload` | 上传文件（unary bytes，100MB 上限） |
| `BaseCommService.Download` | 下载文件 |

## 驱动对比

| 驱动 | 存储位置 | 公开 URL |
| --- | --- | --- |
| `local` | `public/uploads/Ymd/<自动名>` | `{domain}/public/uploads/Ymd/name` |
| `minio` | `uploads/Ymd/{key\|\|rand16}` | `{scheme}://{endpoint}/{bucket}/{key}` |
| `oss` | `uploads/Ymd/{key\|\|rand16}` | `https://{bucket}.{endpoint}/{key}` |

## 配置

```yaml
cool:
  file:
    mode: "local"              # local | minio | oss
    domain: "http://127.0.0.1:8002"
    oss:
      endpoint: "127.0.0.1:9000"
      accessKeyID: "accessKeyID"
      secretAccessKey: "secretAccessKey"
      bucketName: "cool-admin-rust"
      useSSL: false
      location: "us-east-1"
```

<Note>
  `minio` 与 `oss` 共用 `oss.*` 配置项。MinIO 需 `useSSL: false`。
</Note>

## 上传示例

```bash
DATA=$(echo -n "file content" | base64)

grpcurl -H "$H" -d "{\"data\":\"$DATA\",\"filename\":\"a.txt\"}" \
  localhost:8001 base.v1.BaseCommService/Upload
```

```json
{
  "code": 1000,
  "data": {
    "url": "http://127.0.0.1:8002/public/uploads/20260101/qdfvvjx1.txt",
    "path": "public/uploads/20260101/qdfvvjx1.txt"
  }
}
```

## 下载

```bash
grpcurl -H "$H" -d '{"path":"public/uploads/20260101/qdfvvjx1.txt"}' \
  localhost:8001 base.v1.BaseCommService/Download
```

<Warning>
  下载接口有**路径穿越防护**，`../` 会被拒绝。
</Warning>

## UploadMode 兼容说明

`minio` / `oss` 驱动的 `get_mode()` 仍返回 `mode="local"`，
这是为兼容 cool-admin 前端：前端判断 `mode=='local'` 时走后端代理上传。

```json
{ "mode": "local", "type": "local" }
```

## 静态资源

local 驱动的文件落在 `public/` 目录，由部署层 nginx 提供静态服务
（`cool.file.domain` 指向 nginx 地址）。gRPC 服务本身保持纯 gRPC。

```nginx
server {
  listen 8002;
  root /app/public;
}
```
