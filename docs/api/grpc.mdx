## Server Reflection

服务默认启用 gRPC Reflection，可用 `grpcurl` 直接调试：

```bash
# 列出所有服务
grpcurl -plaintext localhost:8001 list

# 查看服务方法
grpcurl -plaintext localhost:8001 describe base.v1.BaseOpenService

# 查看消息结构
grpcurl -plaintext localhost:8001 describe base.v1.LoginReq
```

## 调试技巧

<CodeGroup>
```bash 列出服务
grpcurl -plaintext localhost:8001 list
```

```bash 查看签名
grpcurl -plaintext localhost:8001 describe base.v1.BaseOpenService
```

```bash 带鉴权调用
grpcurl -plaintext -H "authorization: Bearer $TOKEN" \
  -d '{}' localhost:8001 base.v1.BaseOpenService/PersonInfo
```

```bash 开启调试日志
RUST_LOG=debug ./target/release/cool-admin-rust
```
</CodeGroup>

## 鉴权要求

| 接口 | 鉴权 |
| --- | --- |
| `Captcha` / `Login` / `RefreshToken` | 免鉴权 |
| `internal.v1.*` | 免鉴权 |
| 其他所有接口 | 需要 `Bearer <token>` |

## 响应约定

所有响应包含 `code` / `message`：

| code | 含义 |
| --- | --- |
| `1000` | 成功 |
| `1001` | 业务失败（message 为原因） |

详见 [响应约定](/concepts/response)。
