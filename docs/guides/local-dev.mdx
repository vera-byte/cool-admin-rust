`scripts/dev-up.sh` 一键启动本地环境并运行冒烟测试。

## 快速开始

```bash
# 一键启动全部（依赖 + 服务 + 冒烟测试）
./scripts/dev-up.sh

# 仅启动（不测试）
./scripts/dev-up.sh up

# 仅跑冒烟
./scripts/dev-up.sh smoke

# 停止（保留 MySQL/Redis 数据）
./scripts/dev-up.sh down
```

## 启动组件

| 组件 | 容器 | 端口 | 说明 |
| --- | --- | --- | --- |
| MySQL | `cool-mysql-test` | 3306 | 业务数据库 |
| Redis | `cool-redis` | 6379 | 分布式会话 / 缓存 |
| etcd | `cool-rust-etcd` | 2379 | **APISIX 配置中心** |
| APISIX | `cool-rust-apisix` | 9080 / 9180 | 网关 / Admin API |
| 微服务 ×4 | — | 8001–8004 | base / dict / space / task |

```text
容器网络: cool-net（APISIX 经 host.docker.internal 访问宿主机微服务）
```

## 前置条件

- Docker + Docker Compose
- Rust 1.85+ / protoc
- grpcurl（`go install github.com/fullstorydev/grpcurl/cmd/grpcurl@latest`）

## 常见问题

<AccordionGroup>
  <Accordion title="APISIX 启动失败 etcd 不可达">
    确认 etcd 容器在 `cool-net`：
    ```bash
    docker network connect cool-net cool-rust-etcd
    docker restart cool-rust-apisix
    ```
  </Accordion>

  <Accordion title="微服务转发 502/503">
    macOS 需 `--add-host=host.docker.internal:host-gateway`（脚本已内置）。
    Linux 可改用宿主机 IP。
  </Accordion>

  <Accordion title="端口冲突">
    脚本默认端口 3306/6379/2379/9080/9180/8001-8004，
    冲突时先 `./scripts/dev-up.sh down` 清理。
  </Accordion>
</AccordionGroup>
