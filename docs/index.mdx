CoolAdminRust 是 [CoolAdmin](https://cool-js.com) 系列的 **Rust + gRPC** 后端实现，
基于 [tonic](https://github.com/hyperium/tonic) 构建，提供与 cool-admin-go 对齐的业务语义与安全模型。

<Note>
  本项目不使用 Web 框架，对外统一通过 **gRPC** 提供服务（决策 D1–D5 已锁定）。
</Note>

## 技术栈

| 领域 | 选型 |
| --- | --- |
| 运行时 | tokio |
| RPC | tonic 0.12 + prost |
| 数据库 | SQLx（MySQL）+ SQL 迁移 |
| 缓存 | redis-rs（Redis / 内存双模式） |
| 鉴权 | sa-token-plugin-tonic |
| 密码 | argon2（兼容旧 MD5 自动升级） |
| 文件存储 | local / minio / oss |
